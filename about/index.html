MomoTTS is what happens when an indie developer asks an uncomfortable question about every "free" TTS app on the store: where do my words actually go?

AB

Ansari Bilal

20+ apps shipped 14+ HF Spaces 100% on-device advocate

Bilal Ansari — publishing as Ansari Bilal — builds from a simple conviction: the most private app is the one architecturally incapable of leaking. Not a settings toggle, not a promise in a policy — an app with no code path out.

MomoTTS is that belief applied to speech. Neural synthesis used to mean choosing between a monthly invoice and a data trail; Bilal wired Piper and Kokoro models into Flutter isolates so the cloud became optional — then unnecessary. It's free, account-free, and it will read your words on a plane over the ocean.

LINER NOTES · PHILOSOPHY

First principles, pressed to vinyl.

P-01
Offline is a feature, not a fallback
If software only works with a healthy connection, it's renting capability. MomoTTS is bought-and-paid-for the moment you install it — and it costs nothing.
P-02
The sandbox is the contract
Policies can change; process boundaries can't. Keeping synthesis inside the app's memory is the only privacy guarantee that survives acquisition, pivot, and neglect.
P-03
Latency is respect
Background isolates, parallel chunk renders, a UI that never stutters — because a tool that makes you wait is a tool you'll quietly stop using.
P-04
Craft ships free
No premium tier holding the good voices hostage, no export watermarks, no character quotas. The whole studio, one free APK.
